# ElectricSaver

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
우리집 전기 사용량을 입력하면 누진세 구간과 예상 요금을 계산하고 절약 시뮬레이션으로 다음 달 요금을 낮추는 법을 알려주는 생활 계산기

## Problem
한전 누진세 구조가 복잡해 실제 얼마나 아낄 수 있는지 체감하기 어렵고 폭염철 전기요금 폭탄에 대한 불안이 큼

## Target Users
자가/자취 거주 20-50대 가구주, 전기요금에 민감한 1인가구~4인가구

## Core Features
1. 월 사용량(kWh) 입력시 누진구간별 요금 자동 계산
2. 전년 동월 대비 요금 비교
3. 가전제품별 예상 절약액 시뮬레이션
4. 여름철 한시 완화 요금표 자동 반영
5. 가전별 상세 절약 팁 리포트(리워드 광고 시청 후 열람)
6. 우리 동네 평균 사용량 익명 비교

## Monetization
- Model: ads
- Estimated MRR: $157
- Reasoning: 완전 클라이언트 계산 도구라 서버비용 없이 배너 노출 극대화 가능하고, 절약 팁 상세 리포트를 리워드 광고로 게이팅. 다만 요금 확인은 검침 주기(월 1-2회)에 몰려 사용 빈도는 제한적
